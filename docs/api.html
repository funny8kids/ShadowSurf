ShadowSurf API 接口文档

本地控制面接口。桌面 UI、CLI、SDK、IDE 插件共用同一套契约。机器可读规格见 openapi.yaml，可直接导入 Postman / Insomnia / Apifox。

Base URL　http://127.0.0.1:7801
版本　v1
关联 架构设计 前端设计 openapi.yaml

01概述

接口分两套：REST 负责状态查询与命令提交，WebSocket 负责实时事件。任务执行是异步的——POST /v1/tasks 立刻返回 202 与 task_id，进度通过事件流推送。

特性说明
协议HTTP/1.1，JSON 请求体，UTF-8
基址http://127.0.0.1:7801（仅回环，不监听 0.0.0.0）
版本策略路径版本 /v1；破坏性变更才升主版本
时间全部为 Unix 毫秒整数，字段名以 _at 结尾
ID 前缀prf_ 环境 · spc_ 空间 · tsk_ 任务 · stp_ 步骤 · prx_ 代理 · art_ 产物
幂等所有 POST 支持 Idempotency-Key 头，24h 内同 key 返回首次结果

02鉴权与安全

每次启动生成随机 token，写入 ~/.shadowsurf/token（权限 0600）。所有请求携带：

Authorization: Bearer <token>
回环防护

服务校验 Origin 头，仅接受 chrome-extension://、file://、http://127.0.0.1:* 与无 Origin 的本地进程调用。任何网页发起的跨域请求都会被 403 拒绝——这是防止恶意页面通过 localhost 驱动浏览器的关键一道。

同时设置 Access-Control-Allow-Origin 为白名单精确匹配，不使用 *。

3.3 分页与筛选

参数类型默认说明
pageinteger1页码，从 1 开始
page_sizeinteger20最大 100
sortstring—-created_at 前缀 - 表示倒序
qstring—模糊搜索（名称、标签、代理 IP）

3.4 限流

读接口 60 req/s，写接口 10 req/s，任务提交 2 req/s。超限返回 429 并带 Retry-After 秒数。

04资源模型

Profile (环境)
  └─ Space (运行实例)        1 : N，同时最多 1 个活跃
       └─ Task (任务)         1 : N
            └─ Step (步骤)     1 : N
                 └─ Artifact (快照/截图/产出)

4.1 状态枚举

资源状态转移
Profileidle running proxy_error inconsistent启动 → running；代理检测失败 → proxy_error；一致性 < 90 → inconsistent
Spaceopening ready closed创建 → opening → ready；关闭 → closed
Taskqueued running paused done failed cancelled见架构文档 §7.1 状态机
Steppending running ok failed skipped线性推进，失败可重试

方法路径说明

对应 UI 底部的批量操作栏。单次最多 200 个 ID，操作串行执行，返回逐项结果（部分失败不整体回滚）。

07任务 Tasks

核心接口。提交后立即返回，执行过程通过 WebSocket 推送；也可轮询 GET /v1/tasks/{id}。

方法路径说明
POST/v1/tasks创建并启动任务，返回 202
GET/v1/tasks列表，按状态 / 环境 / 时间筛选
GET/v1/tasks/{id}详情，含预算消耗与当前步骤
POST/v1/tasks/{id}/pause暂停（保留上下文）
POST/v1/tasks/{id}/resume恢复
POST/v1/tasks/{id}/cancel取消（保留已产出）
POST/v1/tasks/{id}/takeover转人工接管，返回控制句柄
POST/v1/tasks/{id}/release释放接管，从当前步骤续跑
POST/v1/tasks/{id}/confirm确认 L2 高风险动作
GET/v1/tasks/{id}/steps步骤列表，含证据引用
GET/v1/tasks/{id}/artifacts产物列表（快照 / 截图 / 产出文件）
GET/v1/tasks/{id}/replay回放索引（帧序列 + 动作时间轴）

字段类型说明
profile_id*string在哪个环境下执行

space_idstring复用已有空间；不传则自动创建 shadow 空间

11WebSocket 事件

WS /v1/events 事件流

连接：ws://127.0.0.1:7801/v1/events?token=<token>&since=<seq>。断线重连时带 since 可补发遗漏事件（服务端保留最近 10 分钟）。

字段类型说明
type*string事件类型
seq*integer单调递增，用于补拉
ts*integerUnix 毫秒
dataobject事件负载
事件类型
type触发时机
task.created任务入队
task.step步骤状态变更（每步至少 2 条：running / ok|failed）
task.paused暂停或等待人工确认
task.completed成功结束，含产出摘要
task.failed失败结束，含错误码
task.takeover_requested需要人工接管（验证码 / L2 动作）
space.opened / space.closed空间生命周期
profile.status_changed环境状态变化（含代理异常）
proxy.degraded代理延迟或失败率超阈值
示例：task.step
{
  "type": "task.step",
  "seq": 1024,
  "ts": 1761900210000,
  "data": {
    "task_id": "tsk_5e12a9c3",
    "step": {
      "id": "stp_8c07", "seq": 5,
      "status": "running",
      "intent": "正在提取第 12 条 $29.99"
    },
    "progress": { "current": 12, "total": 20 },
    "cost_cny": 0.19
  }
}
背压

单连接推送上限 200 条/秒。客户端处理不过来时服务端会合并 task.step（只保留最新状态）并丢弃中间帧——完整历史仍可从 REST 补齐，因此客户端不应依赖事件流做全量记录。

13错误码

HTTPcode含义客户端处理建议
400INVALID_ARGUMENT参数校验失败展示字段级错误，不重试
401UNAUTHORIZEDtoken 缺失或失效重新读取 token 文件
403ORIGIN_FORBIDDENOrigin 不在白名单检查调用来源
403POLICY_DENIED动作被策略拦截（L2 未确认）弹出确认框，调 /confirm
404NOT_FOUND资源不存在刷新列表
409SPACE_CONFLICT同环境同 mode 已有活跃空间复用已有 space_id
409PROXY_IN_USE代理被环境引用，无法删除先解绑
422PROFILE_INCONSISTENT一致性分数 < 90引导修复或传 force
422BUDGET_EXCEEDED预算参数非法（如 max_steps > 200）收敛参数
429RATE_LIMITED超限按 Retry-After 退避
500INTERNAL未预期异常带 trace_id 上报
503BROWSER_UNAVAILABLECDP 连接不可用指数退避重试，提示重启
504CDP_COMMAND_TIMEOUT浏览器命令超时重试 1 次后降级
504MODEL_TIMEOUT模型调用超时自动切备用供应商

14SDK 示例

14.1 TypeScript

import { ShadowSurf } from '@shadowsurf/sdk'

const ss = new ShadowSurf()   // 自动读取 ~/.shadowsurf/token

// 1. 建环境
const profile = await ss.profiles.create({
  name: 'Amazon-US-01',
  group_name: '电商',
  os: 'windows_11',
  timezone: 'America/Los_Angeles',
})

// 2. 跑任务（自动订阅事件）
const task = await ss.tasks.run({

import requests, os

TOKEN = open(os.path.expanduser('~/.shadowsurf/token')).read().strip()
BASE = 'http://127.0.0.1:7801/v1'
H = {'Authorization': f'Bearer {TOKEN}'}

task = requests.post(f'{BASE}/tasks', headers=H, json={
    'profile_id': 'prf_7c9a2e4b1d',
    'intent': '采集无线耳机搜索结果前 20 名的标题与价格',
}).json()['data']
