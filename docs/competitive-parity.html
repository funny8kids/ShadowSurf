01结论先行

五条结论。每一条后面跟着可复核的证据，不写「业内普遍认为」这种没有出处的句子。

01

引擎层的差距不在「数量」，在「未覆盖面」

本项目代码实测：_MASK_TABLE 覆盖 17 个宿主对象、61 个属性级触点，加上 document.fonts.check 与 speechSynthesis.getVoices 共 63 个触点，分布在约 30 条独立可检测通道上。对面：GoLogin 文档逐条列出 21 项设置（User-Agent / Orbita 版本 / 屏幕分辨率 / 语言 / Platform / CPU 线程 / RAM / DoNotTrack / OS / 字体列表 / 视频输入 / 音频输入 / 音频输出 / Canvas / WebGL / AudioContext / ClientRects / WebRTC / 时区 / 位置），Multilogin 宣称 55+ 参数，AdsPower 与 BitBrowser 均宣称 50+。但那是「参数个数」，不是「通道个数」。本项目缺的是整条通道消失：battery、mediaDevices、permissions、mediaCapabilities、navigator.connection、WebAssembly 在代码里各 0 次引用；plugins / mimeTypes / maxTouchPoints 只在登记表里出现（为了 toString 收口保留原生 arity），值并没有改写。

02

会被外部检测器真正打中的是三件事，不是三十件事

其一，插桩本身就是一个 tell：被换过的函数必须让 Function.prototype.toString 说得出原话，而 plugins 这类只登记未改写的属性仍然吐宿主真值——两者对照就能定位出改写过。其二，字体 DOM 布局通道没封：document.fonts.check 与 canvas measureText 两条路已接管，用 <span> + offsetWidth 做布局度量的第三条路拦不住，代码里 offsetWidth 0 次引用。其三，TLS/JA3 与 HTTP/2 在 Electron 层做不到，README 已明确列为不承诺项。

03

商业产品的付费墙锁的不是指纹算法

免费档就有可用指纹环境：Multilogin 5 个环境 + 1 个云手机、GoLogin 3 个、AdsPower 2 个、BitBrowser 10 个（且免费档就含 Local API、RPA、SOCKS5/SSH 代理）、Dolphin 3–5 个、MoreLogin 2 个 / 2 用户（含本地 API + Synchronizer + Selenium/Puppeteer）、Undetectable 5 个云环境、Incogniton 10 个。被锁的是另外七样：团队角色与共享、云端（云手机/云浏览器/云同步）、代理市集、扩展与脚本市场、Cookie 机器人、跨工具迁移、并发调度（AdsPower 明确支持到 100 并发线程）。本项目在完整性上领先，在协作与规模上落后——这是两种不同的落后，不要混成一句「我们更强」。

04

2026 年的桌面浏览器 UI 期望是七件套，本项目缺四套令牌与十类原语

七件套 = 侧栏 + 垂直标签 + 命令面板 + AI 侧栏 + 分屏 + 三档主题 + 密度调节，外加骨架屏与动效体系。一手依据：Chrome 146+ 右键 Show Tabs Vertically；Chrome 分屏快捷键 Shift+Alt+N；Edge 支持窗口内切换工作区、工作区置顶与自定义 emoji；Firefox 157 自称「史上最大视觉改版」并新增紧凑模式与一键浅/深主题；Firefox 155 的 Organize Tabs；Chrome 的 AI Mode 进了地址栏、Gemini 走侧栏（可弹出 / 可停靠、上下文最多 10 个标签）；Dia（Arc 将于 2026-12-22 关停后的继任者）提供 Profiles + 侧栏标签 + Tab Groups + 记住布局的 Splits。本项目 tokens.css 的颜色 / 圆角 / 三级阴影 / 焦点环 / 布局尺寸是完整的，暗色也全覆盖，但没有间距阶梯、没有动效时长与缓动、没有层级、没有字阶这四套令牌——app.css 里的动效是 0.12s / 0.14s / 0.16s / 0.18s 手写内联值，没有一处 token 化。

05

MCP 已经是品类标配，本项目却没有接入面——这是最锋利的缺口

截至 2026-11-18 核实到 5 家在售产品已发货 MCP：GoLogin Core MCP Server（gologinapp/gologin-mcp，暴露 profile 创建 / 启动 / 停止 / 列举，适配 OpenAI、Gemini、Claude、Cursor、Copilot）、AdsPower（local-api-mcp-typescript，Claude Desktop 与 Cursor）、Undetectable（Browser MCP + Chromium CDP MCP，undetectable-local-api-mcp-ts，MIT 协议，Claude / Claude Code / Codex / Gemini / Cursor）、Incogniton（MCP）、MoreLogin（Copy to Agent · MCP）。本项目的立项理由就是「AI 原生浏览器」，却连一个 MCP 端点都没有：全仓库检索 mcp 命中 0 处（唯一相关的是 docs/api/openapi.yaml 的注释）。

操作日志无 actor 归属审计链记录了动作，但单用户模型下没有「谁」的维度能做结构上先预留 actor 字段，避免以后改格式
本项目在这一层的护城河

防篡改审计 vs 运营审计，是两件事。竞品的「活动日志」记的是谁在什么时候改了什么；本项目的审计链记的是这条记录是否被改过（每条带前一条哈希，verify() 从头重算定位断裂点）。前者不能否定后者，后者也不能冒充前者——所以不要因为竞品有活动日志就宣称自己有团队审计。

密钥隔离。模型 API Key 与代理凭据只存在于 Agent 进程内存与系统密钥链，渲染进程永不接触；种子完整值不出主进程。

零遥测默认。竞品为了团队功能必然要上报行为数据；本项目默认不上报，这是隐私叙事上的实打实差异。

10三条红线（不可逾越）

这三条是本项目对外表述的硬边界。不夸大能力比夸大能力更值钱——商业产品可以含糊，我们不行，因为我们的用户会照着我们写的去判断风险。

红线一 · 网络层指纹

事实：TLS/JA3 握手指纹、HTTP/2 SETTINGS 与优先级帧、TCP 栈特征在 Electron 层无法伪造。Chromium 网络栈不向 JS / CDP 暴露这些层，Page.addScriptToEvaluateOnNewDocument 也够不着。

禁止措辞：不得写「已伪装网络指纹」「内核级 TLS 伪造」「网络层已对齐」「与真实浏览器网络指纹一致」。

本项目实际怎么说的：README「已知限制」第一条即写「网络层指纹做不到。TLS/JA3、HTTP2 指纹、TCP 栈特征在 Electron 层无法伪造，要等内核 fork。文档里已写明『阶段三之前不承诺』」——口径正确，保持不变。

红线二 · 字体 DOM 布局通道

事实：document.fonts.check 与 canvas measureText 两条字体探测路已接管，白名单外的字体按 fallback 度量；但用 <span> + offsetWidth 做布局度量探测的那条路拦不住，代码中 offsetWidth 引用数为 0。

禁止措辞：不得写「字体已完全伪装」「字体枚举已封死」「字体维度已对齐真机」。

本项目实际怎么说的：README「字体探测只做了一半」，并明确列出第三条路未拦——口径正确。对外必须连同「已接管的两条路」一起说，不许只说前两条。

红线三 · Worker / Service Worker 顶层脚本竞态

事实：CDP Target.setAutoAttach { flatten: true } 已能对 Worker 与 OOPIF 子 target 注入（fingerprint.ts 有 buildWorkerScript 专用源与 WorkerNavigator.prototype 适配，cdp.ts 有 autoAttach 重放记账）；但 Worker 顶层脚本先于注入执行，存在竞态窗口——代码注释已自陈这个代价：「失去『注入早于 worker 顶层脚本』这条保证」。

禁止措辞：不得写「Worker 已覆盖」「上下文全覆盖」「Worker 场景指纹完全一致」。

本项目实际怎么说的：README 目前写的是「Worker 上下文没有注入指纹」，这一条已经落后于代码——代码已实现 Worker 专用注入。对外口径应以代码为准，表述为「Worker 作用域已注入，但顶层脚本存在竞态窗口」，并同步修正 README，不要让文档比代码更悲观。
